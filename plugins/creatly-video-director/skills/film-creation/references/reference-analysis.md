# 参考素材分析

## 目标与边界

从用户有权使用的图片或视频中提取可复用的视觉、空间、镜头和声音规则，再转换为本项目的 Script、Shot、Frame 或 Video 内容。目标不是恢复来源作品的秘密提示词，也不是复制人物身份、品牌、文字、受保护角色或独特设计。

只有当前 Agent 确实能够读取素材像素、视频帧或音轨时才做对应分析。只能读取文件名、链接或元数据时，立即说明缺少的读取能力并请求可访问素材；不能根据标题或缩略图猜测内容。分析结果没有写入画布前，不把它称为项目资产。

## 图片分析

先判断素材是写实影像、插画、平面设计、界面截图、实物摄影还是多格故事板，再按以下顺序记录：

1. **构图锚点**：主体占比、画面位置、朝向、视线空间、裁切、留白，以及前景、中景和背景关系；
2. **主体关系**：人物、服装、姿态、表情、道具及彼此距离；
3. **空间与透视**：地点、固定结构、摄影机高度、水平朝向、俯仰角和透视倾向；
4. **时间与光线**：昼夜、天气、光源类型、方向、软硬、曝光、高光与暗部；
5. **色彩与材质**：主色、辅色、饱和度、反差，以及皮肤、布料、金属、玻璃和空气质感；
6. **媒介与成像**：实拍、动画或插画语言，镜头、颗粒、笔触、渲染和后期特征。

先锁定几何关系和可见事实，再归纳风格。不得让「电影感」「高级感」等高先验词覆盖素材中的真实构图、亮度和材质。多格故事板只提取版式、模块职责和信息层级，不把不同格中的内容误判为同一空间。

## 视频分析

能够读取视频时，按以下顺序执行：

1. 取得真实时长、画幅、分辨率、帧率和音轨可用性；
2. 识别硬切、明确转场和时间跳跃，运镜、主体进出、焦点变化、闪光或变速本身不算切镜；
3. 建立人物、场景、关键道具和声音清单；
4. 逐镜登记起止时间、景别、方位、角度、构图、运镜、动作、光线、对白和音效；
5. 检查时间轴是否连续覆盖全片，镜头时长是否来自真实切点，人物与场景是否都有定义。

镜头时长不应被机械等分。镜头密度异常高或连续多个镜头时长几乎相同时，回看切点，确认是否把连续运镜误拆成多个 Shot。自动切点检测只能提供候选，最终以可见剪辑证据为准。

## 转换为原创项目规则

分析完成后，把内容分成三类：

```text
可直接继承：画幅、镜头节奏、构图关系、光线逻辑、色彩关系、材质和声音结构。
需要改写：人物身份、场景功能、道具、对白、品牌、文字和情节内容。
禁止继承：受保护角色、独特设计、可识别商标，以及用户无权使用的具体表达。
```

只保留对目标项目有作用的规则。风格参考要改写成媒介、色板、光线、镜头、构图和材质等可执行描述；镜头参考要改写成 Shot 的 `visualPurpose`、`blocking`、`composition`、`cameraAngle`、`lens`、`cameraMove`、`duration` 和 `transition`。

## 写入画布

- 用于新作品定调时，把参考结论写入 Script 的「导演意图」「摄影与声音基准」和「项目制作设定」。
- 用于单个镜头时，只更新受影响的 Shot、Frame 和 Video，不重写无关节点。
- 用于成片诊断时，把问题定位到主体资产、场景设计、Shot、Frame 或 Video 的最高层真实原因，再按 [修订与恢复](revision-and-recovery.md) 修改。
- 使用 `updateNode` 或 `createNode` 后必须回读 FULL 快照。聊天中的分析表不能替代画布证据。

任何参考媒体都不能绕过主体、场景、连续性、付费确认或生成状态契约。参考文件能被读取，不表示它已经成为 Sky 的可绑定生成资源；只有实时 schema 接受并成功写入的真实资源绑定才具有该含义。
