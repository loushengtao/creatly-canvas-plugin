# 叙事短片创作

先阅读[创作方法](references/method.md)，再阅读[MCP 执行协议](references/mcp-execution.md)。按用户已有材料与当前任务范围开展工作，定稿剧本和对白优先。

1. 完成 dev 网站 OAuth 授权，用标准 MCP `tools/list` 确认实时能力，读取目标画布 JSON。
2. 从已有节点整理故事、场景、镜头、资产、声音与播放顺序，明确本次缺口。制作依赖与成片顺序分别表达，不额外创建可写 DSL 源文件。
3. 通过实时节点与主体工具写入已确定的内容、关系及正式生成参数，回读验证。只要求剧本或建图时不自动生成媒体。
4. 用户要求生成时，先准备关键参考，再按依赖推进目标镜头。严格使用实际部署的生成和状态工具，费用遵循后端确认流程。
5. 核对真实媒体、连续性和剪辑顺序后组装成片。没有视觉或听觉证据时，请用户复核对应产物，不凭任务成功宣称质量合格。

续作先读当前 JSON 和原任务回执，只更新本次明确范围。创作细节按方法指南处理，接口名称、参数、权限与恢复步骤以 MCP 执行协议及实时工具定义为准。
