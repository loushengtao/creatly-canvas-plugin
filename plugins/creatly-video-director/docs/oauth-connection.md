# 账号连接与自动续期

元极通过远程 Streamable HTTP MCP 和标准 OAuth 连接账号。宿主（Codex、Claude Code 等）完成首次浏览器登录、PKCE、凭据保存和自动续期，插件只声明服务器与创作技能。这种模式无需本地画布服务或保持网页打开。

## 持续使用

1. 首次连接，在插件分支对应的网站登录并授权空间。
2. 宿主保存授权凭据；后续对话、重启和同一环境更新复用已有连接。
3. 访问令牌过期后，宿主自动用刷新令牌换取新令牌，并保存响应中的新刷新令牌。旧刷新令牌不能再次使用。
4. 只有授权撤销、刷新令牌到期、宿主凭据丢失、账号/空间切换或环境切换后才需要重新授权。客户端注册丢失等后端缺陷需要先修复，再重新连接一次。

后端默认访问令牌为 30 分钟、刷新令牌为 30 天。每次成功续期签发新的 30 天刷新令牌；连续使用可持续续期，停止使用直至刷新令牌到期后需要重新授权。具体时长以环境配置和 token 响应为准，插件不能保证永久登录。

同一环境更新必须保留插件名 `creatly-video-director`、MCP 名 `yuanji`、域名和 `/api/agent/mcp/v2` 地址。日常更新使用宿主的插件更新操作，不清除凭据，不安装第二个指向同一地址的手动 MCP。安装目录和版本不是访问令牌存储位置。

## 按错误处理

| 现象 | 检查与处理 |
| --- | --- |
| 工具未出现在当前任务 | 检查插件启用、宿主加载和实际连接状态；缺少工具本身不能证明未授权 |
| 401 | 让宿主执行标准自动刷新；若宿主明确提示需要授权，再重新连接一次 |
| `invalid_client` | 检查服务器是否仍有该客户端注册，以及 token endpoint 的认证方法；不要当作账号密码错误 |
| `invalid_grant` | 检查刷新令牌到期、撤销、轮换后旧令牌重用或并发刷新；不要循环重复同一个刷新请求 |
| 403 | 检查已授权账号、空间和资源权限，重新登录不能自动补足权限 |
| 429、5xx、stream timeout | 保留连接，按限流提示或服务状态重试读取；写入和生成先读回结果，避免重复提交 |

排障记录宿主版本、插件版本、环境、错误码、时间和 traceId 即可。不要记录或发送 Cookie、Authorization 请求头、client secret、access token、refresh token 或授权回调中的 code。

## 后端部署验收

持续连接需要测试环境后端发布 OAuth 客户端保留修复：客户端只在满足过期条件且没有任何关联授权记录时清理，不能因为访问令牌过期或注册超过一天就删除有效连接。令牌和客户端注册必须持久化在同一环境数据库，应用更新保留签名密钥。

部署后用一个隔夜的真实 Codex/Claude 连接调用 `listProjects`，确认可以自动续期且账号/空间正确；再在下一次宿主重启后复测。已被旧清理任务删除的注册无法从只存哈希的授权记录恢复，需要用户重新授权一次。代码测试通过不等于已完成上线和真实宿主验收。

## 平台托管连接

Canva/HeyGen 的官方插件还可以声明由平台注册的账号连接。元极当前以直连 MCP 的标准 OAuth 达到一次授权、自动续期的体验；没有已注册的平台连接 ID 时，不在 manifest 中填写虚构的 `.app.json`。后续接入平台托管需要先完成平台侧注册和 OAuth 配置，再将实际连接加入插件。直连 MCP 不需要等待这一步才能持续使用。
